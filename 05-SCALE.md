# SCALE

## Growth Loops
- Referral: share deployed agent → credits
- GitHub: stars & forks create new users
- Content: weekly X/LinkedIn posts of real agent builds

## Analytics Schema
Track: installs, auth success rate, diagram edits, commit success, deploy success, retention cohorts, error rates (especially 404 / OAuth).

## Automation
- LLM-powered support bot for common auth/deploy errors
- Auto A/B testing of headlines and onboarding
- Weekly product iteration cadence based on error + usage data

## Key Risks to Monitor
- Chrome store review friction
- GitHub / Vercel API rate limits and auth edge cases
- Trust (users letting an extension write to their repos)
